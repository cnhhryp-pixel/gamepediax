# GamePediaX

Static-first gaming knowledge site for **gamepediax.com**.

## Structure
- Home
- Games
- Wiki
- Guides
- Tools
- About
- SEO: sitemap.xml, robots.txt, canonical metadata
- Static 404 page

## Deployment
Works as a zero-build static site on Cloudflare Pages or GitHub Pages.
For Cloudflare Pages, use no build command and set the output directory to the repository root.
