Subnautica Resource Planning Reference

A Subnautica resource planning reference for targeted gathering, inventory space and converting materials into progression.

Resource runs are most efficient when one main material is tied to one clear upgrade or construction goal.

Choose the target resource first

Know what you need before leaving so the route and inventory decisions stay focused.

Protect inventory space

Do not begin a resource run with unnecessary cargo.

Use known routes for efficient gathering

Exploration and collection are different jobs. Familiar areas are better for fast material runs.

Convert resources quickly

Craft, build or store the haul as soon as you return so the run creates visible progress.
