Baldur's Gate 3 Rest and Resource Management Guide

A Baldur's Gate 3 rest and resource management guide for using limited abilities efficiently without hoarding them forever.

Resource management is about using enough power to make progress without spending everything on routine encounters.

1. Use renewable options for routine situations

Basic attacks and reusable abilities can handle easier encounters while stronger limited resources stay available.

2. Spend powerful resources when they change the outcome

Do not hoard every strong ability. If using it prevents major damage or ends a dangerous encounter quickly, it may be worth the cost.

3. Rest when the party has lost meaningful options

If several characters can no longer perform their roles effectively, continuing may cost more than resetting resources.

4. Review what actually ran out

After a difficult section, identify which resources became the bottleneck so the next preparation is more deliberate.
