Subnautica Depth Progression Checklist

A Subnautica depth progression checklist for oxygen, vehicles, navigation, power and safe return planning.

Going deeper is not only about reaching a number. Each depth increase should be supported by navigation, oxygen, power and a clear way home.

1. Improve breathing margin before longer dives

More oxygen or a better travel method gives you more time to explore and less pressure to rush decisions.

2. Keep the route understandable

Use markers and recognizable landmarks so deeper exploration does not become a navigation problem.

3. Check the systems that keep you moving

A depth upgrade is less useful if vehicle power, repairs or supplies become the new bottleneck.

4. Treat the first deeper trip as reconnaissance

Learn the route and hazards first, then return for focused resource collection.
