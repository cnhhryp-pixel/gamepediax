Subnautica Resource Run Checklist

A reusable Subnautica resource run checklist for choosing a target material, clearing inventory and returning efficiently.

Resource gathering works best when each trip has one primary target. Focus prevents inventory clutter and shortens the time between finding materials and using them.

1. Choose the material before leaving

Know the primary resource you need and where you are most likely to find it.

2. Clear enough inventory space

Remove unrelated cargo so the trip can actually produce a meaningful amount of the target resource.

3. Use a known route when efficiency matters

Exploration and gathering are different jobs. Use familiar areas for fast collection and new areas for discovery.

4. Convert the haul into progression immediately

Unload, craft or store the resource as soon as you return so the trip creates a clear upgrade or next step.
